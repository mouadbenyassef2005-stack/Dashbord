QAIDAH – Quran lesen lernen (MVP)

1) Node.js (LTS) installieren: https://nodejs.org
2) Dieses ZIP entpacken, im Ordner "quran-lernapp" ein Terminal öffnen (in VS Code: Terminal > Neues Terminal)
3) Nacheinander ausführen:
     npm install --legacy-peer-deps
     npm run dev
4) Im Browser (Chrome oder Edge) öffnen: http://localhost:3000
   Neue Funktion: Lesetraining > "Quran lesen" (Sure Al-Burudsch, Mikrofon, Live-Korrektur)
